# خليتي | Khalti Beekeeping

تطبيق أندرويد باللغة العربية لإدارة المناحل وخلايا النحل، ومتابعة الفحوصات والإنتاج والتكاليف.

## أهداف المشروع

- تسجيل خلايا المنحل بهوية رقمية ورمز QR فريد.
- حفظ بيانات الملكة وقوة الطائفة والإطارات والحضنة.
- تسجيل الفحوصات والملاحظات السريعة والصوتية.
- تنظيم التغذية والعلاجات وإضافة العاسلات ومواعيد الفرز.
- متابعة الطرود المأخوذة من كل خلية.
- تسجيل المصروفات والإنتاج والمبيعات وحساب تكلفة كيلو العسل وصافي الربح.
- توفير أدوات مساعدة لتحليل صور الإطارات والتنبيه إلى مؤشرات محتملة، مع ضرورة مراجعة النتائج وعدم اعتبارها تشخيصاً مؤكداً.

## التقنيات المقترحة

- Flutter وDart لتطبيق Android.
- SQLite للتخزين المحلي في المرحلة الأولى.
- QR لتمييز الخلايا وفتح سجلاتها.
- دعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار.

## خطة التطوير

1. إنشاء هيكل تطبيق Flutter وتجهيز قاعدة البيانات.
2. بناء إدارة المناحل والخلايا وسجل الفحوصات.
3. إضافة QR وإدارة الطرود والتقويم والتذكيرات.
4. إضافة المخزون والحسابات والتقارير.
5. دراسة دمج الطقس والتعرف على الصور بعد اختبار النسخة الأساسية.
